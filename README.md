## Backend & Database (optional)

This repo includes a minimal Express + MySQL backend in the `server/` folder to power the frontend with a real database.

Quick start:

1. Import `public/belajar_bahasa_daerah.sql` into your MySQL instance (creates `bahasa` database with required tables).
2. Copy `server/.env.example` to `server/.env` and set your MySQL credentials and `JWT_SECRET`.
3. In `server/` run:

```sh
npm install
npm run dev
```

4. Set the frontend environment variable and start the frontend:

```sh
# in project root
# macOS / Linux
export VITE_API_BASE=http://localhost:4000/api
# Windows Powershell
$env:VITE_API_BASE = "http://localhost:4000/api"

npm run dev
```

When `VITE_API_BASE` is set, the app will fetch data from the backend instead of using the local mock data.
